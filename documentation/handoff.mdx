---
title: "Animated handoff"
description: "Remove the native overlay with no animation, then run your own exit on a matching JavaScript view."
keywords: ["useHandoff", "replica", "reanimated", "bootsplash"]
---

`useHandoff` waits until a JavaScript view has the manifest's background and logo, laid out and loaded. It then removes the native overlay with `SplashAnimation.None`. Your `animate` function runs after that, so the first frame of the animation is the same picture the overlay was drawing.

Use this when the exit is yours: a fade, a scale, or a mask that opens over the app. Use [`hideAsync`](/hide) when a built-in fade or slide is enough.

## Reveal through a circle

This is the React Conf pattern. A round mask the size of the logo scales up and the logo fades. The app is already a child of the mask, so it was under the splash the whole time.

Install the animation dependencies in a bare or Expo app:

```bash
npx expo install react-native-reanimated react-native-worklets @react-native-masked-view/masked-view
```

Add `react-native-reanimated/plugin` as the last Babel plugin.

```tsx components/AnimatedBootSplash.tsx
import MaskedView from "@react-native-masked-view/masked-view";
import { type ReactNode, useState } from "react";
import { StyleSheet, View } from "react-native";
import Animated, {
  Easing,
  runOnJS,
  useAnimatedStyle,
  useSharedValue,
  withTiming,
} from "react-native-reanimated";
import { type Manifest, useHandoff } from "react-native-nitro-splash";

const MAX_SCALE = 10;
const manifest: Manifest = {
  background: "#0B1220",
  logo: { width: 120, height: 120 },
};

export function AnimatedBootSplash({
  animationEnded,
  children,
  onAnimationEnd,
}: {
  animationEnded: boolean;
  children: ReactNode;
  onAnimationEnd: () => void;
}) {
  const [ready, setReady] = useState(false);
  const opacity = useSharedValue(1);
  const scale = useSharedValue(animationEnded ? MAX_SCALE : 1);
  const opacityStyle = useAnimatedStyle(() => ({ opacity: opacity.value }));
  const scaleStyle = useAnimatedStyle(() => ({ transform: [{ scale: scale.value }] }));

  const { container, logo } = useHandoff({
    manifest,
    ready,
    logo: require("../assets/logo.png"),
    statusBarTranslucent: true,
    navigationBarTranslucent: false,
    animate: () => {
      opacity.value = withTiming(0, { duration: 250, easing: Easing.out(Easing.ease) });
      scale.value = withTiming(MAX_SCALE, { duration: 350, easing: Easing.back(0.75) }, () => {
        runOnJS(onAnimationEnd)();
      });
    },
  });

  return (
    <>
      {!animationEnded && <View style={container.style} />}
      <MaskedView
        style={StyleSheet.absoluteFill}
        maskElement={
          <View style={[container.style, { backgroundColor: "transparent" }]}>
            <Animated.View
              onLayout={() => setReady(true)}
              style={[
                {
                  backgroundColor: "black",
                  borderRadius: manifest.logo.width,
                  width: manifest.logo.width,
                  height: manifest.logo.height,
                },
                scaleStyle,
              ]}
            />
          </View>
        }
      >
        {children}
      </MaskedView>
      {!animationEnded && (
        <View {...container} style={[container.style, { backgroundColor: "transparent" }]}>
          <Animated.Image {...logo} style={[logo.style, opacityStyle, scaleStyle]} />
        </View>
      )}
    </>
  );
}
```

`logo.style` is the manifest frame. Do not give that image a different width. The handoff is invisible only when this view matches the overlay.

Call `preventAutoHideAsync()` once at module scope, then render the splash around your app:

```tsx App.tsx
const [splashVisible, setSplashVisible] = useState(true);

<AnimatedBootSplash
  animationEnded={!splashVisible}
  onAnimationEnd={() => setSplashVisible(false)}
>
  <YourApp />
</AnimatedBootSplash>
```

## When animate runs

`animate` runs once, after all of these are true:

- the container has laid out
- the logo image has loaded (`onLoadEnd`)
- the brand image has loaded, when the manifest has a brand and you passed a `brand` source
- `ready` is `true` (it defaults to `true`)

On Android, the replica is shifted by the status bar and navigation bar heights unless you set `statusBarTranslucent` or `navigationBarTranslucent`.
